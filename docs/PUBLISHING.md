# 更新与同步

仓库：https://github.com/zhyu-24/course-study-room

用户于2026-09-22授权：本项目公开发布；由Agent完成的后续课程更新在检查通过后自动提交并推送到此仓库。**不启用后台目录监听，不自动上传尚未核查的任意文件。**

## 每次更新

1. 核验新增素材与实际课堂范围。此次用户许可确认涵盖本轮现有资料；未来新增第三方材料需取得公开转载许可后纳入发布，缺授权的资料留在本地，不能自动公开。
2. 更新Markdown底稿、来源及教材索引，生成网页。课堂知识变更执行相应学术核验；网页逻辑变更执行离线浏览器回归。
3. 检查待提交差异，无凭据、私人通信、备份和临时文件；新大文件符合.gitattributes的Git LFS规则。
4. 运行同步脚本。正常情况下不再重复询问是否推送；认证失效、远端冲突或授权范围不明时停止发布并说明原因，不强制覆盖远端。

~~~sh
python AI_Course_Archive_v2/scripts/sync_github.py --message "更新课程资料" --release
~~~

脚本刷新统一入口、提交当前授权变更、推送并核对远端提交；--release额外制作完整离线包并发布版本，适用于课程内容或网页变更。仅修正文档时可省略--release。脚本不代替源材料权限审查和浏览器测试，也不自行判定学术正确性。

首次运行需要git、Git LFS及已登录的gh。Git凭据使用系统凭据管理器，不写入项目。远端有新提交时先人工/Agent核查并合并；脚本不自动rebase或force push。

## 为什么既有Git LFS又有离线包

教材、音频、原始ZIP使用Git LFS，以免超出普通Git单文件限制。维护者可通过git pull与git lfs pull更新。普通读者优先下载Releases中的course-study-room-offline.zip，避免误下载只有大文件指针的源码ZIP。

离线包取自当前Git跟踪文件，装入本机真实LFS文件，校验ZIP与所有主体资源后上传；SHA256SUMS.txt用于下载校验。参见[GitHub Releases说明](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)。

## 排除项

备份、tmp、Python字节码、环境文件和本机测试截图/报告不上传；被教材索引引用的持久缓存保留。本机验收文档中的部分截图或完整性报告属于开发附件，不包含在公开包中；课程正文、原图、教材和播放来源按构建清单检查，不允许缺失。

提问辅助已于2026-09-22经用户通过真实“阶跃加窗/取单边”提问验证并确认任务完成。验证的是复制定位→人工发送→读取原页答疑，不代表Codex内置批注载荷已测试。
