# 课程资料编译规范 v2

## 目标与适用边界

让学习者通过讲义从头到尾复习本讲，通过忠实整理稿回顾教师讲解，通过来源记录回到材料。长度由知识内容决定，不以摘要字数控制。Raw 永不覆盖；每次核对课程、讲次、来源与目的目录。旧文档只作线索，不能代替重读新增/有疑点的原始资料。

课程维持 Course_Index、Global_Knowledge、Global_Source_Map；每讲维护 Notes、Source Map，有转写时新增 Transcript_Corrected。HTML、页面图片、manifest 与 QA 报告是可重建辅助产物，不要求用户逐份维护。只有获得保存学习记录的授权后才新增课程级 Study_Log。

## 输入与课堂范围

逐文件记录指纹、页数/时长以及 actual processing：读取文本、渲染、视觉核验、音频核听是不同状态。可访问性与已核验范围分别填写。转写的最后一个时间戳通常是最后一段的起点，不是音频结束时刻。

全章课件不等于本节已讲范围；以课堂材料确定覆盖，回顾上讲/口头补充/未讲预览单独记录。无录音不虚构口头内容，无转写不自动生成教师授课稿。缺源允许交付明确限定范围的 draft。

2026-09-22用户认可缺素材产出后，固定本轮已验证的方法：缺录音/转写时交付以实际课件及已核验教材为依据的完整讲义，正文开头说明材料边界；不虚构教师稿、问答、课堂顺序或已讲范围。录音、转写、教材的缺失分别登记；不因缺源把讲义压缩为主题摘要。已有转写但无录音时可忠实整理，保留无法核听的疑点。用户认可效果不自动把draft升级为reviewed。

## 对齐和订正

先完整阅读当前转写及对应课件，再划分稳定片段 T01…；每段记录原稿起止定位、页或页段、讲义落点及确定性。时间为转写段落锚点，不冒充音频逐秒核验或精确翻页时刻。一个片段可跨多页，页面可重复。

整理稿保留实质性解释、例子、有效问答、学习要求和顺序；移除无意义口头赘词，改为自然段。不得以主题摘要替代整理稿。

术语订正可在多处明确上下文与课件支持下完成。改变公式、符号、数字、否定词或结论的订正必须有可靠依据并记录原表述/结果/定位。疑似教师口误与 ASR 错误无法区分时，不断言是谁说错；保留原稿含义并添加编者注。AI 的推导和补充不得写成教师原话。

重点核听范围为改变知识含义的疑点。没有可靠音频处理能力时，列出定位和影响，保留待核听状态；获取时长或再次 ASR 不等于完成原音核验。

## 教学编写

Notes 沿课堂学习主线展开，必要时局部重排。主要定义说明条件、符号、直觉；主要图给出可见图像和读图解释；主要推导保留起点、非显然步骤、依据与结果；主要例题保留题设、过程与答案状态。框图、口头例子和开场复习不可因不在旧笔记中而遗漏。

FACT 为来源直接支持内容；教师解释属于 EXPLANATION；编者补足的推导/前置知识标为补充推导或教材补充（DERIVED）；未知或冲突就地标注并汇总（UNCERTAIN）。数学补充依据现有来源推导即可，不假装是新查得的事实。来源优先级服务于核验，不能用教材覆盖“教师实际讲了什么”的记录。

每个主要主题提供少量可回答的自测及折叠答案。正文使用主题级来源入口；机器字段留在索引。课堂作业与编者自测分开，未经要求不默认代做全部作业。

## 教材渐进处理

首次核验实际版本与目录，小节标题、印刷起页、PDF 定位及习题位置进入 Textbook_Index。非当前章节的页段可从目录推算，但标明 locator-only，遇到具体题目必须回页确认，不将推算标作已读。

本讲相关页及习题页进入 `Global/Cache/<完整SHA256>/`。渲染、文本提取、OCR、视觉核验分别记录；局部可搜索文本允许为人工核验的节选索引，必须注明不是全文 OCR。重用旧 tmp 图时需证明与当前 PDF 页相符（图像比对或原页核查），不能只信文件名。

全书不预先逐页总结。读取当前范围的必要上下文，留下可检索的局部结果；之后按问题增量精读。缓存损坏或来源改变时重新生成受影响页面。

后补教材时先核验实际原页，更新受影响讲义、来源记录和教材索引，再生成单讲网页及统一入口。用户随课程推进补拍的PDF各自作为新来源原样归档，以各自指纹和实际页段建立映射；重叠页不覆盖旧原件，目录页不等于正文已入库，不将部分拍摄文件自动视为全书。发现差异时记录版本/拍摄差异，不能无依据继承旧题号、页码或纠错结论。

## 生成接口

底稿采用 UTF-8 Markdown；公式用 `\(...\)`/`\[...\]`；稳定锚点用 `<a id="N01"></a>` 和 `<a id="T01"></a>`。Notes 链接 `Transcript_Corrected.md#T01`；整理稿链接 `Lecture_Notes.md#N01`。普通图片使用相对路径，讲义图随讲次 assets 保存。

Source Map 用 `<!-- ALIGNMENT_JSON` 开始、`END_ALIGNMENT_JSON -->` 结束的 JSON 数组供生成器读取。字段为 id、title、start、end（秒；未知结尾为 null）、time（可读时间段）、pages（PDF 页数组）、notes（Notes 稳定锚点）、certainty（对齐依据与不确定性）。它与同文件人工可读表格必须一致，不另外维护第二份对应关系。整理稿每段保留可读的时间/页码行，并添加 `<!--SEGMENT T01-->` 标记；生成器把标记变为音频定位按钮和对应页图库。课件图片命名为 `assets/slides/p-01.jpg`，位数至少两位。

生成器从底稿构建三视图 HTML，重写底稿间链接，携带本地公式库、样式、图像，禁止 CDN 和外部数据请求。没有整理稿时不显示其视图。状态保持 draft；人检后才能 reviewed。改变底稿后重新生成页面并核对输入指纹。

## 统一阅读入口 v2.1

项目根目录index.html为默认入口，课程和讲次标题、单元顺序及主题由Course_Index生成。新增讲次先补齐课程索引；构建发现索引与实际讲次不一致时必须报错，不能静默漏讲。Markdown仍为唯一内容底稿。

`scripts/build_review.py <讲次目录>`默认重建单讲兼容页并刷新统一入口；仅排查兼容页时可用`--no-portal`。只调整导航或新增Global资料时运行`scripts/build_portal.py`。统一入口复用底稿渲染逻辑，按需加载site/data中的本地脚本，不依赖服务器、fetch文件读取或CDN。site是派生产物，图片、音频和教材原页仍引用课程内文件，搬迁时需保留整个项目目录结构。

新界面复用N/T稳定锚点，路由记录课程、讲次、视图和锚点；Global资料使用document参数。数据包保留来源相对路径、输入SHA256、对齐片段和原始LaTeX，供后续准确定位使用。可选提问辅助单独维护在optional/question-helper，主体不依赖它；仅整理可复制的选区与来源，不自动发送或调用模型。历史Review.html和信号L02冻结产物不因全项目构建而重写。
