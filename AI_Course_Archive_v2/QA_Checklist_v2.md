# v2 验收清单

当前语言修订版v2.0.1；阅读界面v2.1。语言验收与学术核验分别记录。

## 面向学习者的语言验收（v2.0.1）

- [ ] 从头到尾通读完整讲义，开篇说明学习问题，章节和推导衔接自然，必要解释充分；没有因精简遗漏实质内容。
- [ ] 正文、标题、图注、自测与默认阅读工具不反复出现编写者自我说明、订正过程或处理状态；有效记录已归并到来源或验收记录。
- [ ] 必要补充融入主线；自学、作业、预习与拓展按学习用途区分，来源身份不逐段打断正文。
- [ ] 条件、易错点和实际影响仍清楚；没有把未确定的知识写成确定结论，也没有以泛泛免责声明替代解释。
- [ ] 对照修改前后核查公式、条件、例题、课堂要求和实质片段；课堂回顾保留实际顺序，不混入后补讲解。
- [ ] 检查生硬拼接、机械过渡、口号和重复提醒；关键词扫描仅作辅助，不能替代整讲阅读。
- [ ] Markdown与生成网页一致，桌面和窄屏实际看图检查；用户阅读反馈、工程检查、学术自检与原音核听状态分别记载。

L01试改已获用户认可；本轮验收范围为其他全部既有讲次。原始资料指纹不变，已认可L01内容不重写；历史试点的冻结副本保留在备份中，当前文件按本轮授权更新。

## 必须执行的内容验收

- [ ] 所有来源登记；处理状态与事实一致，原件指纹未变。
- [ ] 全文转写分段均有落点；每个实质教学片段保留解释/例子/有效问答，删减有边界。
- [ ] 本讲课件页逐页映射到讲义或标明封面、目录、致谢、未讲预览，不把只有一张图视为已讲清。
- [ ] 定义含条件，推导可跟随，例题可复算，图和框图可读；自测有答案和依据。
- [ ] 课初/课中/课末对应关系逐项抽查；关键订正均有证据；原音未核听不宣称已核听。
- [ ] 教材实际版本已核验；目录级导航完整；具体题面与条件回原页核查。
- [ ] 至少一道作业题和一个公式条件从索引定位成功；重复检索命中缓存；来源指纹改变不命中旧缓存。
- [ ] draft 不自动提升为 reviewed；用户阅读体验尚未确认时报告里写明。

## 网页与机械验收

- [ ] Markdown 底稿和生成页面输入指纹一致；所有本地链接/图片/锚点存在。
- [ ] 断网 file URL 打开：公式无错误、图片加载；三个视图、目录、跨视图跳转、图片放大工作。
- [ ] 从页首滚动到页尾检查；桌面和窄屏无正文溢出，长公式允许局部横向滚动。
- [ ] 视觉检查典型图文、推导、自测、整理稿与来源页；不能仅用 DOM 存在代替视觉验收。
- [ ] Raw 未变化；未授权文件保持原样；学习记录未未经确认新增。

结果区分：工程检查通过 / 内容自检通过 / 待核听项 / 用户体验待确认。已限定影响的不确定项可交付 draft；错误结论、关键来源虚构、丢失实质性片段属于阻断项。

## v2.1统一入口增量验收

统一入口读取当前已归档讲次，按本轮授权范围生成与检查。

- [ ] Course_Index与讲次目录一致，新增讲次无遗漏，首页/课程目录标题准确。
- [ ] 断网逐讲、逐视图检查；缺转写时无虚构课堂回顾或播放器。
- [ ] 刷新、前进/后退、跨视图及同名N/T锚点定位正确；错误路径有明确提示。
- [ ] 教材索引、PDF页定位、图片放大、音频定位和切换停止正常。
- [ ] 桌面/390px窄屏、长公式及打印检查通过；实际看图检查。
- [ ] Raw及历史冻结备份指纹不变；构建输入指纹与当前Markdown底稿一致。
- [ ] 旧单讲入口仍可用；新阅读体验与学术复核状态分别记录。
