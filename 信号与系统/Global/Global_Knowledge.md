# 信号与系统 — Course Knowledge Map

> 课程结构由第三版上册教材与 L01 课件共同核验；下册和独立教学大纲尚未归档。

## 1. 课程主线

- 课程研究如何描述、分析和处理信号，以及系统对输入产生何种输出响应。`[G1 Ch.1 §1.1, PDF p.17–19 / printed p.1–3; L01-S1 PDF p.21, p.30]`
- 结构由连续时间部分走向离散时间部分；先在时域建立分析，再进入傅里叶、拉普拉斯、Z 变换、DFT/FFT 等变换域工具。`[G1 Ch.1 §1.8, PDF p.53–55 / printed p.37–39; L01-S1 PDF p.6; L01-S2 00:08:37–00:10:42]`
- 课程强调把数学表达、物理概念与工程应用结合，而不只是套题。`[L01-S1 PDF p.9; L01-S2 00:15:31–00:17:27]`

## 2. Course Structure

```text
绪论
  ↓
连续时间时域分析 → 傅里叶变换 ↔ 拉普拉斯变换 → 傅里叶变换应用 → 矢量空间
  ↓
离散时间时域分析 → Z 变换 / DTFT → DFT / FFT → 滤波器
```

| Topic | Core question | Prerequisites | Used by | Main locations |
|---|---|---|---|---|
| 信号描述、分类与运算 | 如何用函数和波形表达、辨认与变换信号？ | 微积分、复数基础 | 后续全部分析 | G1 Ch.1；L01 |
| 奇异信号、系统性质与 LTI | 如何用冲激分解信号、判定系统性质并利用线性和时不变性？ | 信号描述与自变量变换 | 卷积、连续时域分析与变换法 | G1 Ch.1 §1.4–§1.7；L02 |
| 连续时间分析 | 怎样由微分方程、起始状态及冲激响应求输出？ | 绪论概念、LTI | 傅里叶、拉普拉斯变换 | [L03讲义](../Lectures/L03/Review.html)；G1 Ch.2 |
| 傅里叶级数 | 如何从周期波形求系数、幅相谱并解释带宽与逼近误差？ | 正交性、复指数、LTI | 傅里叶变换与频域分析 | [L04讲义](../Lectures/L04/Review.html)；G1 §3.2–3.3 |
| 傅里叶变换 | 如何用频域表征信号？ | 连续时域、复指数 | 变换应用、离散变换 | G1 Ch.3 |
| 离散时间分析 | 如何处理采样后的序列和数字信号？ | 连续/离散关系 | Z 变换、DFT/FFT、滤波器 | G1 Ch.1 §1.8 的总览；下册待提供 |
