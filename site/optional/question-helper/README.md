# 提问辅助插件 v1

2026-09-22。主阅读界面仍为v2.1；插件可选、默认关闭，不需要Codex、账号、API或服务才能阅读课程。

## 使用

1. 在课程复习室右下角点击“提问辅助”启用。
2. 选中文字/公式后点击“就此提问”。公式若只选中一部分，会补成完整原始LaTeX，避免复制到重复的数学渲染文本。
3. 图片先点击放大，再点击“询问这张图”。材料包含真实本地路径和图注，不冒充图片已上传。
4. 填写问题，点击“复制问题与定位”，粘贴到Codex对话发送。也可展开完整材料手动复制；自动复制被拒绝时会自动选中材料。
5. 切换课程、讲次、视图或锚点会清除未发送选区及输入，避免旧问题错误关联到新资料。关闭辅助会移除面板、图片按钮和事件监听；问题不写入磁盘或学习记录。

复制材料包含课程、讲次、视图、主题、N/T或标题锚点、底稿绝对路径、来源记录、网页深链接、所选原文、必要所在段落和选中图片的路径。长选区上限12000字符、段落上下文上限1600字符；达到上限时明示截断并保留原文件定位。跨出当前正文的选区不处理。

## 与Codex的关系

当前实现是人工发送的提问材料整理器，不宣称直连当前Codex会话、自动发送或接收回答。普通浏览器同样可以使用复制功能。接收者无本地项目访问能力时，路径不代表它已取得文件；提示词明确要求如实说明这一点。

[官方浏览器说明](https://learn.chatgpt.com/docs/browser?surface=app)描述了开启批注、点选元素/框选区域、添加批注后发送对话消息的操作。本轮未取得用户实际发送的原生批注样本，因此没有把原生批注的具体载荷或本机端到端联动记为已验收；网页中仅提供操作说明，不使用未公开的桌面接口。

## 独立性

- 主体portal.js、portal.css和课程数据包不导入、不调用、不等待插件，原有阅读逻辑不修改。
- 构建器仅在插件源文件齐全时附加独立加载器；可选文件复制失败不阻止主页面生成。
- 默认只显示启用按钮；点击后再加载插件。Shadow DOM隔离面板样式；图片对话框仅临时增加一个按钮，停用时移除。
- 初始化异常和事件异常只清理辅助层；失败提示可关闭/重试。超时/文件缺失显示辅助不可用，主体继续工作。
- 不覆写主体函数或浏览器原型，不访问Codex内部API，不注入正文，不修改来源或底稿。无存储、轮询、模型请求及外部资源。
- 源码在本目录，构建复制到site/optional/question-helper。完全不带插件时运行：

~~~powershell
python AI_Course_Archive_v2/scripts/build_portal.py --without-helper
~~~

此选项仅影响本次构建；默认构建可重新带上启用按钮，但插件仍默认关闭。删除本目录或任一必需JS源文件后，构建器也会自动省略辅助层。部署给无Codex用户时，默认页面也能完整离线阅读，无需专门构建。
