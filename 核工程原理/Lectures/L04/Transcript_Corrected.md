<a id="T01"></a>
## T01 · 上讲截面和平均自由程

时间：00:00–04:29；课件PDF：81–85（上讲回顾），86（指定自学）。[讲义](Lecture_Notes.md#N01)

<!--SEGMENT T01-->

上节课引入了微观截面与宏观截面。微观截面 \(\sigma\) 用靶作单位，\(1\,\mathrm b=10^{-24}\,\mathrm{cm^2}\)；宏观截面对多种靶核写成 \(\Sigma=\sum_iN_i\sigma_i\)，单位是长度的倒数。平均自由程 \(\lambda=1/\Sigma\)，计算时要让截面、核密度和长度单位一致。

课堂给出天然铀金属例题：材料密度为 \(19\,\mathrm{g/cm^3}\)，总宏观截面已知为 \(0.15\,\mathrm{cm^{-1}}\)。此时不必使用密度，直接得到平均自由程约 \(6.67\,\mathrm{cm}\)。老师请大家课后看课件中的其他平均自由程例题。

<a id="T02"></a>
## T02 · 为什么需要中子数密度

时间：04:29–08:36；课件PDF：87–88。[讲义](Lecture_Notes.md#N02)

<!--SEGMENT T02-->

有了截面，还要知道单位时间、单位体积内发生多少次裂变、散射或吸收。为此先定义中子数密度：单位体积中的自由中子数。堆芯各处有燃料、慢化剂和吸收体，数目并不均匀；此处数的是能够与靶核作用的自由中子，不是原子核内束缚的中子。裂变是主要中子来源，吸收等过程又会减少中子数。

老师布置思考题：无限大、均匀、无泄漏反应堆的功率密度为 \(100\,\mathrm{MW/m^3}\)，每次裂变平均放出 \(2.5\) 个中子，中子平均寿命 \(0.1\,\mathrm{ms}\)，求任意时刻的中子数密度。关键缺口是每次裂变释放的能量；可看课件后续内容或自行查询，课堂不公布答案。

<a id="T03"></a>
## T03 · 通量密度的径迹意义与单位题

时间：08:36–13:52；课件PDF：89–93。[讲义](Lecture_Notes.md#N03)

<!--SEGMENT T03-->

中子通量密度定义为 \(\phi=nv\)：单位体积内的中子在单位时间内走过的总径迹长度。沿不同方向走过的长度都要计入，所以它是标量，不是有方向的净流量。其单位可写为 \(\mathrm{cm^{-2}s^{-1}}\)，但物理意义不能只凭单位理解成穿过某固定面积的净中子数。老师提到蒙特卡罗计算中的径迹长度统计法，并说明本课把“中子通量密度”“中子通量”和“中子注量率”用于这一量。

例题给出 \(0.0253\,\mathrm{eV}\) 中子速率约 \(2200\,\mathrm{m/s}\)、密度 \(8\times10^8\,\mathrm{cm^{-3}}\)，要求通量密度。口头计算特别提醒速率先换成 \(\mathrm{cm/s}\)。按题面相乘为 \(1.76\times10^{14}\,\mathrm{cm^{-2}s^{-1}}\)；原转写的数量级口述与此不一致，核算与待核听位置见[来源记录](Lecture_Source_Map.md)。

<a id="T04"></a>
## T04 · 反应率密度与总反应率

时间：13:52–17:49；课件PDF：94。[讲义](Lecture_Notes.md#N04)

<!--SEGMENT T04-->

核反应率密度数单位时间、单位体积内的反应次数。通量是这一体积、这一时间内的总径迹长度，而平均自由程说明平均走多远发生一次相应反应，所以可写 \(r=\phi/\lambda=\phi\Sigma\)。选总截面得到总反应率密度，选裂变截面得到裂变反应率密度。全体积的反应率还须将各处的密度累加；均匀时相当于再乘体积。

老师反复区分两个密度：材料核密度 \(N\) 用来算 \(\Sigma=N\sigma\)，自由中子数密度 \(n\) 用来算 \(\phi=nv\)。微观截面属于核数据，但具体材料和能量条件仍要选对。

<a id="T05"></a>
## T05 · 通量能谱及高通量堆思考

时间：17:49–21:40；课件PDF：95–96。[讲义](Lecture_Notes.md#N05)

<!--SEGMENT T05-->

对选定材料和能量，若宏观截面变化不大，提高反应率往往要提高通量。老师请大家思考高通量堆怎样实现更高的中子通量。实际堆中中子有不同位置、方向和能量，不能只用一个数描述：\(n(E)\,\mathrm dE\) 与 \(\phi(E)\,\mathrm dE\) 分别数对应能量间隔的数密度和通量贡献。课堂都称为中子能谱，二者通过能量相关的速率联系。将 \(\Sigma(E)\phi(E)\) 在能量上积分，才得到多能系统的反应率密度。

<a id="T06"></a>
## T06 · 反应率等效与本节自学内容

时间：21:40–26:31；课件PDF：97–105。[讲义](Lecture_Notes.md#N05)

<!--SEGMENT T06-->

截面随能量变化，通量也有能谱，因此定义平均截面来简化计算。老师要求平均前后算出的反应率一致，故用中子通量谱作为权重：\(\bar\Sigma=\int\Sigma(E)\phi(E)\,\mathrm dE/\int\phi(E)\,\mathrm dE\)。有了平均截面，反应率密度就可写成 \(\bar\Sigma\phi\)。老师强调理解这个权重为何出现，胜于只记公式。

由中子通量分布可算各类反应率，再结合每次裂变的能量算功率；求中子通量分布是反应堆物理的主要工作。课件后面的英文术语、铝等材料计算例题和平均自由程题目留作课后阅读，课堂未逐题讲解。

<a id="T07"></a>
## T07 · 两套分类与四类重点反应

时间：26:31–31:58；课件PDF：106–111。[讲义](Lecture_Notes.md#N06)

<!--SEGMENT T07-->

老师先问上讲的两种作用机理。同学回答“散射和吸收”后，老师提醒：按机理应是势散射和形成复合核的反应；形成复合核后也可能再放出中子。为了工程上使用方便，才按结果分为散射和吸收。散射含弹性、非弹性；吸收含辐射俘获、裂变以及放出质子、\(\alpha\) 等反应。总截面为散射截面与吸收截面之和。

堆内主要关注弹性散射、非弹性散射、辐射俘获与裂变。课堂追问“中子状态改变”包括什么，回答有位置、运动方向和能量。这些量的分布将成为后续分析对象。

<a id="T08"></a>
## T08 · 弹性散射、热中子与质量效应

时间：31:58–36:40；课件PDF：112–114。[讲义](Lecture_Notes.md#N07)

<!--SEGMENT T08-->

弹性散射可类比刚性球碰撞：中子与靶核系统的动能、动量守恒，靶核内能不变。它是裂变中子慢化的主要途径之一。所谓热中子，是与介质热运动接近平衡的中子，并非温度“很热”。老师提出高速中子撞上静止靶核后的能量问题：中子通常会失去一部分动能，也可能在某些碰撞情形下几乎不变。与氢、氧等较轻核碰撞的能量转移通常比与铀等重核碰撞显著；判断仍取决于质量与散射角。

<a id="T09"></a>
## T09 · 非弹性散射阈能与快堆低能中子

时间：36:40–44:01；课件PDF：115–121。[讲义](Lecture_Notes.md#N08)

<!--SEGMENT T09-->

非弹性散射经历复合核过程，出射后余核处于激发态，随后可发射 \(\gamma\) 射线。动量守恒，但一部分动能转成核激发能，所以动能不单独守恒。该反应有阈能，重核较低的激发能级使其高能中子非弹性散射值得关注；课堂用碳-12的 4.43 MeV 和铀-238的 0.045 MeV 对比。非弹性散射能显著降能，却不能在入射中子低于阈能后继续发生。

老师进一步问：快堆没有专设慢化剂，为什么仍有较低能中子？钠、钾、氧等较轻的堆内核也能弹性散射；不同冷却剂质量数使单次能量转移不同。中子逃出堆芯、经外部材料慢化后返回，也可能贡献低能部分。这是开放思考，不只选一个原因。老师要求现阶段记住阈能、重核作用和常见的 \(\gamma\) 退激，不要求复杂机理。

<a id="T10"></a>
## T10 · 从俘获过渡到活化与辐射防护

时间：44:01–45:48；课件PDF：122–123。[讲义](Lecture_Notes.md#N09)

<!--SEGMENT T10-->

散射讲完后转入辐射俘获：中子被靶核吸收，产物可能放射性，材料随之活化。课中休息前后，老师用聚变与加速器举例说明活化问题。氘氚聚变会产生中子；加速器带电粒子打靶也可能产生中子，这些中子再与周围材料作用。辐射防护因而还要考虑感生放射性，不能只看初始粒子束。

<a id="T11"></a>
## T11 · 同位素生产和中子活化分析

时间：45:48–49:32；课件PDF：123–124。[讲义](Lecture_Notes.md#N09)

<!--SEGMENT T11-->

活化可用于生产新核素。老师以钴-59俘获生成钴-60为例，介绍钴-60衰变热用于深海长期低功率供能的研究设想。不同核素活化后发出的 \(\gamma\) 射线能量可作识别线索，因此能用中子活化分析测材料成分。课堂举光绪头发砷含量检测的故事，说明这种方法的应用面与高灵敏度；历史死因的最终论证不由课堂故事本身完成。

<a id="T12"></a>
## T12 · 由活度反推中子通量

时间：49:32–51:28；课件PDF：125。[讲义](Lecture_Notes.md#N09)

<!--SEGMENT T12-->

活化法也可测中子。照射处通量决定俘获产生率，活化产物的衰变带来可测射线；测得射线信号后，可按已知截面、衰变常数及测量条件反推通量，继而估计堆的功率等级。课堂点到活化片、“跑兔”装置和自给能探测器，建议课后调研具体原理和适用条件。

<a id="T13"></a>
## T13 · 易裂变核、可裂变核与裂变自由程

时间：51:28–57:43；课件PDF：126–127。[讲义](Lecture_Notes.md#N10)

<!--SEGMENT T13-->

裂变属于中子吸收反应。老师把热中子即可有效诱发裂变的铀-235、铀-233、钚-239、钚-241列为易裂变核；铀-238、钍-232、钚-240则需要足够高能中子等条件。看铀-235和铀-238裂变截面图，要认清坐标是对数刻度：低能端铀-235仍有明显裂变截面，铀-238主要在较高能区出现可观裂变。课堂用同一纯铀-235核密度下热中子、快中子裂变自由程比较题，提醒先判断“截面大则自由程短”，再核算选项；直觉来自规律，也不能替代计算。

<a id="T14"></a>
## T14 · 复合核激发能与四类反应回顾

时间：57:43–01:00:26；课件PDF：128–131。[讲义](Lecture_Notes.md#N10)

<!--SEGMENT T14-->

为什么铀-235较容易由低能中子诱发裂变、铀-238不易？老师沿复合核图示解释：中子结合进来提供激发能，若足以跨越裂变所需的势垒，低动能中子也可能诱发裂变；若还差一部分，就需中子的入射动能补足。临界能细节请参考拉马什教材。随后老师把四类反应归纳为：散射主要改变中子状态，俘获移去中子，裂变吸收入射中子又产生新中子，影响中子收支。

<a id="T15"></a>
## T15 · 铀-238俘获与钚-239

时间：01:00:26–01:04:19；课件PDF：132–133。[讲义](Lecture_Notes.md#N11)

<!--SEGMENT T15-->

接着看对核工业有影响的具体反应。压水堆常用燃料中铀-238占很大比例，铀-238俘获中子后成铀-239，经镎-239转为易裂变的钚-239。这条链与提高铀资源利用率、快堆路线有关，但需要足够的中子来源和实际燃料循环。课堂问其俘获对链式反应影响是否小，老师指出核素数量与截面都要看，并预告铀-238吸收与温度负反馈关系重要。

<a id="T16"></a>
## T16 · 钍-232俘获与钍基堆讨论

时间：01:04:19–01:07:25；课件PDF：134–135。[讲义](Lecture_Notes.md#N11)

<!--SEGMENT T16-->

钍-232吸收中子后先成钍-233，再经两次 \(\beta^-\) 衰变到易裂变的铀-233。老师指出钍资源较丰富，但天然钍-232本身不是易裂变燃料，必须先转化。他介绍了当时课堂所知的国内钍基熔盐堆研究、拟议重大专项和不同技术路线；这些项目进度与规模属于课堂时点信息。课堂要求课后了解中国相关研究进展，以及熔盐燃料、固体燃料配熔盐冷却剂等方案。

<a id="T17"></a>
## T17 · 氢的俘获与轻水、重水

时间：01:07:25–01:10:48；课件PDF：136–138。[讲义](Lecture_Notes.md#N12)

<!--SEGMENT T17-->

氢-1俘获中子变成氘。单个氢核的俘获截面虽不算大，但水量多，而且慢化后较低能的中子就在慢化剂中，未回燃料区前便可能被氢吸收。这会降低压水堆的中子经济性。老师对比重水吸收较弱，并预告后续会讲宏观散射截面、慢化能力与慢化比。

<a id="T18"></a>
## T18 · 铀-235的俘获与热堆设计思路

时间：01:10:48–01:14:52；课件PDF：139–140。[讲义](Lecture_Notes.md#N12)

<!--SEGMENT T18-->

铀-235吸收中子后可能裂变，也可能辐射俘获为铀-236，因此不能把吸收次数全算成裂变。俘获支路无法凭设计完全取消，但可选择更有利的能区。老师对着裂变截面和俘获截面曲线，引导比较两种通道的竞争；用水作慢化剂可较快把中子带入热能区，让铀-235裂变有较大机会。这是理解热堆的一条物理线索，实际堆设计还要满足多种约束。

<a id="T19"></a>
## T19 · 钠冷快堆中的钠

时间：01:14:52–01:17:57；课件PDF：141–142。[讲义](Lecture_Notes.md#N13)

<!--SEGMENT T19-->

钠冷快堆须关注钠与水接触的化学事故，也须关注钠被中子活化。钠-23俘获生成钠-24，\((n,2n)\) 可生成钠-22；两者是钠冷却剂放射性的来源。看钠-23吸收和弹性散射截面图时，老师提醒图上某能区截面高，并不等于它对快堆最重要，还要看快堆中子实际落在哪些能区。

<a id="T20"></a>
## T20 · 氧-16生成氮-16与活度计算

时间：01:17:57–01:20:54；课件PDF：143–144。[讲义](Lecture_Notes.md#N14)

<!--SEGMENT T20-->

氧-16受足够高能中子作用可发生 \((n,p)\)，成为氮-16。虽然满足阈能的裂变中子比例小，氮-16仍是运行中水系统的重要辐射来源：它半衰期约 7 秒，伴随高能 \(\gamma\) 射线。老师联系厂房通风、净化和负压设计，说明要控制空气中的活化产物与污染物迁移。

课堂问冷却剂出口活度从 \(3.3\times10^6\) 降至 \(3\,\mathrm{Bq/cm^3}\) 需要多久；用 \(A=A_0 2^{-t/T_{1/2}}\) 可算得约 \(140\) 秒，少于 3 分钟。这里计算仅对应题设的氮-16单核素衰变情形。

<a id="T21"></a>
## T21 · 医疗暂存类比和氮-14生成碳-14

时间：01:20:54–01:22:43；课件PDF：144–145。[讲义](Lecture_Notes.md#N14)

<!--SEGMENT T21-->

老师把活度随时间下降的方法联系到医疗放射性废物暂存：应等到满足相关管理要求再处理，不能只凭刚生成时的活度判断。他接着讲氮-14的 \((n,p)\) 反应生成碳-14，可发生于含氮环境，也与自然界碳-14的来源有关。短寿命的氮-16与长寿命的碳-14不能用同一暂存时间处理。

<a id="T22"></a>
## T22 · 氮化铀、硼反应和中子源

时间：01:22:43–01:25:06；课件PDF：145–149。[讲义](Lecture_Notes.md#N15)

<!--SEGMENT T22-->

课堂以氮化铀与二氧化铀对比，介绍氮化铀较高导热能力的吸引力，也提出氮-14转成碳-14可能影响材料的担忧，提到用氮-15制备氮化铀的研究思路。随后快速带到硼-10的 \((n,\alpha)\) 反应：它能吸收中子，可用于控制材料、中子探测和硼中子俘获治疗。最后转到铍-9在 \(\alpha\) 或 \(\gamma\) 作用下产生中子，以及不同中子源的产额、成本差异。原转写末尾核素名称混乱；此处按第 146–149 页可确认的反应归并，待核听位置见[来源记录](Lecture_Source_Map.md)。
