# 核工程原理 — Course Knowledge Map

> 当前地图以已编译的课堂材料为骨架，并以教师自编主教材 G1 作为全局知识的首要依据。它不是教材摘要；仅在课程实际讲到、需要章节定位或建立必要关系时增量更新。

## 1. Course Purpose and Scope

- 课程以核反应堆物理原理为主要内容，讲授裂变核能工程的基础原理，强调物理原理与工程问题之间的联系。`[L01-S1 PDF p.5–8]`
- 课程在专业知识体系中处于基础位置，为反应堆热工水力、控制、结构、安全、系统设备、材料等后续课程提供物理基础。`[L01-S1 PDF p.6–8]`
- 课程目标不仅是记忆概念，还包括复杂物理系统建模、数学工具和数值计算能力。`[L01-S1 PDF p.14]`

## 3. Topic Maps

### 3.1 核反应堆物理

**Core question**

如何描述并定量分析中子裂变链式反应系统，使能量释放可控，并预测反应堆行为？`[L01-S1 PDF p.19–21, p.33–38]`

**Core concepts**

- 中子运动规律：能量、位置、运动方向与时间。
- 核素变化规律。
- 反应性效应与反馈。`[L01-S1 PDF p.33]`

**Connections and downstream use**

- 反应堆热工水力、控制、结构与安全：反应堆物理给出功率、中子与核素行为的基础。
- 核工程：课件将核反应堆物理定位为核工程的核心学科与应用物理学科。`[L01-S1 PDF p.35–38]`

**Primary course locations**

- 课堂：[[../Lectures/L01/Lecture_Notes|Lecture 01]]
- 主教材：`G1 Ch.1–12`；后续按实际授课主题建立到具体章节/页码的映射。
- 参考教材：`G2` 只在主教材未覆盖、概念需要辅助解释或需核对差异时使用。

### 3.2 压水堆系统

**Core question**

受控裂变释放的核能如何经一回路、蒸汽发生器和二回路转换为电能？`[L01-S1 PDF p.22–29]`

**Core concepts**

- 反应堆压力容器、堆芯、控制棒、稳压器、蒸汽发生器、主泵。
- 汽轮机、发电机、冷凝器、给水与冷却系统。
- 核岛、常规岛及辅助/附属厂房。`[L01-S1 PDF p.22–29]`

**Connections and downstream use**

- 反应堆热工水力：冷却剂输运与换热。
- 反应堆控制与安全：控制棒、反应性、余热排出与安全壳。
- 核电厂系统与设备：一、二回路和厂房系统。
